# Poverty-Classification
Poverty Classification in Bolivia Using Satellite Imagery  
Project Title
Poverty Classification in Bolivia Using Satellite Imagery  
Project Description
This project uses computer vision to classify poverty levels in Bolivia using satellite images. The dataset is categorized into three levels: Low Poverty, Medium Poverty, and High Poverty. The model relies on TensorFlow and Keras, utilizing the EfficientNetB0 architecture for image classification. Key configuration settings include resizing images to 224x224, a batch size of 32, a learning rate of 0.001, and a training cycle of 5 epochs.
